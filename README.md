# CERISNOW White Pro, landing page

Catalogue envoyé aux cabinets dentaires et instituts (FR / AR, mode sombre, demande d'essai par WhatsApp).

- Tout le réglage est en haut de `index.html` (`CERISNOW_CONFIG`) : numéro WhatsApp, images, liste des résultats.
- Pour changer une image : remplacer le fichier dans `images/` en gardant le même nom.
- Site statique, déployé sur Vercel.
