آخر تحديث: 2026-05-28

───────────────────────────────────────────────────────────────
 [1] نظام الحسابات والمنتجات
───────────────────────────────────────────────────────────────
- إدارة كاملة للمنتجات (إضافة / تعديل / حذف / تصنيف)
- إدارة الحسابات المرتبطة بكل منتج مع حالة توفرها
- متغير commissionRate لكل منتج على حدة
- عداد مخزون (stock) + توفر (available)
- عرض الحسابات مع إخفاء/إظهار بيانات الدخول

───────────────────────────────────────────────────────────────
 [2] نظام الطلبات والأرباح
───────────────────────────────────────────────────────────────
- إنشاء طلبات جديدة للبائعين مع اختيار المنتج + مدة
- رفع ملف إثبات دفع (صورة/مستند) بحد 5MB → base64
- عرض الطلبات بحالتها (قيد الانتظار / مقبول / مرفوض)
- حساب العمولات تلقائياً لكل طلب حسب commissionRate
- عرض العمولة في جدول الطلبات للأدمين

───────────────────────────────────────────────────────────────
 [3] نظام البائعين
───────────────────────────────────────────────────────────────
- لوحة تحكم بائع منفصلة
- عرض الرصيد (الأرباح - المسحوبات)
- صفحة السحوبات: طلب سحب + اختيار وسيلة الدفع الافتراضية
- الملف الشخصي: تعديل الاسم، رقم الهاتف، وسيلة الدفع، معلومات الدفع
- إظهار/إخفاء بيانات الحسابات المسلمة

───────────────────────────────────────────────────────────────
 [4] نظام السحوبات (إدارة الأدمين)
───────────────────────────────────────────────────────────────
- صفحة إدارة سحوبات للأدمين (طلبات pending + تمت المعالجـة)
- قبول الطلب مع رفع وصل دفع (صورة/مستند)
- رفض الطلب مع إدخال سبب
- إشعار للبائع عند القبول أو الرفض
- عرض الرصيد القابل للسحب لكل بائع

───────────────────────────────────────────────────────────────
 [5] إدارة الأدمين المتقدمة
───────────────────────────────────────────────────────────────
- لوحة تحكم كاملة مع إحصائيات (مبيعات، أرباح، طلبات، بائعين)
- تعديل البائعين: الاسم، الهاتف، العمولة، وسيلة الدفع
- سجل النشاطات (audit logs) مع تصدير CSV
- وسائل دفع قابلة للتخصيص (أيقونة، حد أدنى، تفاصيل)
- إدارة الإشعارات مع تصفية حسب النوع

───────────────────────────────────────────────────────────────
 [6] DeepSeek AI
───────────────────────────────────────────────────────────────
- شات مباشر مع DeepSeek API (إعداد مفتاح API + الموديل)
- أدوات سريعة: توليد إشعارات، توليد Landing Pages، سياق النظام، نسخ تسويقية
- توليد Landing Pages ذكي: يعدّل المنتج أولاً، يُولّد HTML كامل
- قالب Landing Page مظلم (glassmorphism) مع عداد تنازلي، أقسام مميزات، آراء عملاء، طرق دفع
- حفظ وتاريخ الصفحات المولدة مع إمكانية النشر/الإخفاء

───────────────────────────────────────────────────────────────
 [7] CRM واتساب
───────────────────────────────────────────────────────────────
- صفحة CRM خاصة بالأدمين
- عرض جميع العملاء (من الطلبات) مع تواريخ آخر طلب
- اختيار عميل وإرسال رسالة واتساب عبر wa.me
- متغير {name} في القالب يُستبدل باسم العميل

───────────────────────────────────────────────────────────────
 [8] Supabase Sync
───────────────────────────────────────────────────────────────
- ربط اختياري بقاعدة Supabase للتخزين السحابي
- مزامنة يدوية (syncNow) وتلقائية (saveDB)
- تحميل البيانات من Supabase
- جميع الجداول مدعومة: users, sellers, products, accounts, orders, commissions, withdrawals, notifications, landingPages, aiGenerations, auditLogs, settings

───────────────────────────────────────────────────────────────
 [9] الوضع النهاري / الليلي (Day/Night Theme)
───────────────────────────────────────────────────────────────
- زر تبديل الثيم في أعلى الشاشة (قمر/شمس)
- حفظ التفضيل في إعدادات المستخدم
- Class .light-theme على body يعكس كل الألوان
- Transition سلس بين الثيمات (0.35s)
- التوافق مع prefers-reduced-motion
- Scrollbar مخصص بلون متناسق مع الثيم

───────────────────────────────────────────────────────────────
 [10] تلغرام - إشعارات فورية (Telegram Bot)
───────────────────────────────────────────────────────────────
- إعداد Bot Token + Chat ID من صفحة الإعدادات
- زر اختبار إرسال رسالة
- إرسال إشعار فوري عند كل حدث مهم (طلب جديد، سحب، رفض، الخ)
- يتم دمجها تلقائياً مع دالة addNotification
- رسائل بتنسيق HTML

───────────────────────────────────────────────────────────────
 [11] تحسينات الواجهة والتصميم
───────────────────────────────────────────────────────────────
- ثيم زجاجي (glassmorphism) داكن مع حواف شفافة
- تصميم متجاوب مع 4 نقاط قطع (1200px / 1024px / 768px / 480px)
- قائمة تنقل علوية sticky + شريط سفلي للموبايل
- شريط إجراءات سريعة (quick action bar) عائم
- بنر إعلاني قابل للتخصيص
- رسوم متحركة (fadeIn, scaleIn, slideUp, stagger)
- نظام إشعارات منسدل (dropdown)
- نافذة تأكيد مخصصة (confirmDialog)
- Toast notifications مخصصة
- دعم كامل للغة العربية (RTL)

───────────────────────────────────────────────────────────────
 [12] شريط الإجراءات السريعة (Quick Bar) - Popup
───────────────────────────────────────────────────────────────
- تحويل الشريط إلى زر دائري ينبثق منه menu بسلاسة
- cubic-bezier animation عند الفتح/الإغلاق
- إغلاق تلقائي عند النقر خارج الشريط

───────────────────────────────────────────────────────────────
 [13] نظام المحفظة Wallet (متكامل)
───────────────────────────────────────────────────────────────
- Balance / Pending Balance / Withdrawable Balance لكل بائع
- Transactions History (سجل المعاملات كامل)
- Internal Transfers (تحويل رصيد بين البائعين)
- recalcWallet() تحسب الرصيد تلقائياً من الطلبات والسحوبات
- صفحة محافظ للأدمين (admin-wallet-all) لعرض أرصدة الجميع

───────────────────────────────────────────────────────────────
 [14] نظام الكوبونات والخصومات (Coupons)
───────────────────────────────────────────────────────────────
- إنشاء كوبون بنسبة % أو مبلغ ثابت
- صلاحية (تاريخ انتهاء) + حد استخدام (usage limit)
- كوبون خاص بمنتج معين أو لجميع المنتجات
- validateCoupon() + applyCoupon() للتطبيق الذكي

───────────────────────────────────────────────────────────────
 [15] Smart Pricing AI + AI Copywriting Generator
───────────────────────────────────────────────────────────────
- getSmartPricing(): يقترح أفضل سعر بناءً على المبيعات والمنافسين
- يعرض الطلب (مرتفع/متوسط/منخفض) وأفضل وقت للتسويق
- AI Copywriting: توليد نصوص TikTok / Facebook / Landing / WhatsApp
- مدمج مع DeepSeek API

───────────────────────────────────────────────────────────────
 [16] نظام Analytics احترافي
───────────────────────────────────────────────────────────────
- trackVisit() تسجل كل زيارة للصفحات
- عدد الزوار الفريدون (unique visitors)
- Conversion Rate + Bounce Rate
- أفضل المنتجات + مصادر الزيارات
- getAnalytics() تحسب كل الإحصائيات

───────────────────────────────────────────────────────────────
 [17] نظام Live Chat داخلي
───────────────────────────────────────────────────────────────
- محادثة مباشرة: Admin ↔ Seller
- واجهة شات كاملة مع فقاعات وطرفين
- إشعارات فورية عند وصول رسالة جديدة
- إظهار عدد الرسائل غير المقروءة لكل بائع
- سجل المحادثات محفوظ في chatMessages[]

───────────────────────────────────────────────────────────────
 [18] نظام Tickets & Support
───────────────────────────────────────────────────────────────
- فتح تذكرة من البائع مع: موضوع، أولوية (منخفضة/متوسطة/عالية/عاجلة)، مرفق
- البائع يرفق ملف (صورة/مستند/zip)
- الأدمين يرد ويُحدّث الحالة (قيد المعالجة/تم الحل/مغلقة)
- إشعار للبائع عند الرد

───────────────────────────────────────────────────────────────
 [19] نظام نسخ احتياطي Backup كامل
───────────────────────────────────────────────────────────────
- إنشاء نسخة احتياطية يدوية (createBackup)
- استعادة نسخة (restoreBackup)
- تصدير JSON كامل (exportDB)
- استيراد ملف JSON (importDB)
- تخزين حتى 30 نسخة مع label + حجم الملف

───────────────────────────────────────────────────────────────
 [20] نظام مراقبة الأخطاء (Error Monitoring)
───────────────────────────────────────────────────────────────
- logError() تسجل: المصدر، الرسالة، الرابط، التاريخ
- إرسال تنبيه تلغرام تلقائي عند كل خطأ
- صفحة admin-errors لعرض آخر 100 خطأ
- زر مسح الكل

───────────────────────────────────────────────────────────────
 [21] نظام Device Sessions + AI Assistant
───────────────────────────────────────────────────────────────
- addSession(): تسجيل الأجهزة المتصلة لكل مستخدم
- عرض: المنصة، الـ User Agent، آخر نشاط
- Logout Remote (قطع الجلسة عن بُعد)
- AI Assistant داخلي للبائع: مساعد ذكي يساعد في البيع والتسويق
- يقترح تحليلات المنتجات ونصوص إعلانية مخصصة
